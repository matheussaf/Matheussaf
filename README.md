## Projetos em Destaque

### **Jarvis: Assistente de IA no Terminal**
Assistente autônomo executado via CLI em Python. Integra a API da Anthropic com rotinas de *tool calling* para automação de tarefas locais, manipulação de arquivos e execução de comandos no terminal, com confirmação prévia para operações de risco.
* **Stack:** Python, Anthropic SDK, Rich UI, Tool Calling.
* **Repositório:** [Ver código](https://github.com/matheussaf/jarvis)

### **Pokémon Battle**
Jogo de batalha Pokémon para dois jogadores no navegador, consumindo dados dinâmicos da PokeAPI em tempo real.
* **Stack:** HTML5, CSS3, JavaScript (ES6+), PokeAPI. 
* **Link:** [Jogar Agora](https://matheussaf.github.io/pokemon-battle/) | [Repositório](https://github.com/matheussaf/pokemon-battle)

### **Quem é esse Pokémon?**
Jogo interativo estilo quiz com silhueta, sistema de dicas progressivas por erro, suporte às gerações 1 a 9, três níveis de dificuldade e interface estilizada no formato de TV retro dos anos 90.
* **Stack:** JavaScript, PokeAPI, Retro UI/CSS. 
* **Link:** [Jogar Agora](https://matheussaf.github.io/quem-e-esse-pokemon/) | [Repositório](https://github.com/matheussaf/quem-e-esse-pokemon/)
