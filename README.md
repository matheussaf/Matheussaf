## 🚀 Projetos em Destaque · Featured Projects

### 🤖 [Jarvis: Assistente de IA no Terminal](https://github.com/matheussaf/jarvis)
Assistente autônomo executado via CLI em Python. Integra a API da Anthropic com rotinas de *tool calling* para automação de tarefas locais, manipulação de arquivos e execução de comandos no terminal, com confirmação prévia para operações de risco.
* **Stack:** Python, Anthropic SDK, Rich UI, Tool Calling.

### 🎮 [Pokémon Battle](https://github.com/matheussaf/pokemon-battle)
Jogo de batalha Pokémon para dois jogadores no navegador, consumindo dados dinâmicos da PokeAPI em tempo real.
* **Stack:** HTML5, CSS3, JavaScript (ES6+), PokeAPI. | **[Jogar Agora](https://matheussaf.github.io/pokemon-battle/)**

### 📺 [Quem é esse Pokémon?](https://github.com/matheussaf/quem-e-esse-pokemon)
Jogo interativo estilo quiz com silhuetas, sistema de dicas progressivas por erro, suporte às gerações 1 a 9, três níveis de dificuldade e interface estilizada no formato de TV retro dos anos 90.
* **Stack:** JavaScript, PokeAPI, Retro UI/CSS. | **[Jogar Agora](https://matheussaf.github.io/quem-e-esse-pokemon/)**
