## Projeto em destaque · Featured project

### 🤖 Jarvis: assistente de IA no terminal

Assistente pessoal em Python, executado via CLI. Usa a API da Anthropic com *tool use* (agentic loop) para rodar comandos, ler e escrever arquivos, e **sempre pede confirmação antes de ações destrutivas**. Interface no terminal com Rich. *Personal AI assistant for the terminal: Python, Anthropic SDK, tool calling, human confirmation on risky actions.*
